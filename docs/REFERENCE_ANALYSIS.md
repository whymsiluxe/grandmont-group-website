## 1. Sequel — ГЛАВНАЯ БАЗА

**URL:** `https://styles.refero.design/style/1bd3b2ba-9ad9-44ed-9130-03f9d94de821`
**Live reference:** sequel.co

### Take
- Строго ахроматичная палитра (0% colorfulness): чистый чёрный, тёплый кремовый (#fffdf9-подобный), три нейтральных серых — единственный источник цвета: кинематографичная тёплая портретная фотография.
- Типографика: геометрический сан-сериф (аналог VisueltPro) + дисплейный сериф для одного акцентного слова (аналог Bradford, курсив, только для "легенды"/hero-слова).
- Headline weight 300 ("шёпот, не крик") — тонкий вес на крупных заголовках создаёт премиальность через сдержанность, не через жирность.
- Uppercase tracked labels (0.05–0.08em) — типографика делает работу, которую другие сайты отдают цвету.
- Компоненты: pill-controls, matte cards #202020, единственные тени — функциональные (мягкая тень под кремовой кнопкой, rim-light на бэйджах).

### Don't take
- Не копировать сам шрифт VisueltPro/Bradford — только принцип пары "геометрический сан + дисплейный сериф-акцент".

### Адаптация под Promonta
Это основа общей палитры и настроения всего сайта — near-black canvas, тёплый ivory-акцент, минимум chrome, крупные пустые зоны. Применимо к hero и общему тону (dark mode как основной регистр).

## 2. Vivid+Co

**URL:** `https://styles.refero.design/style/8875b14e-c59a-492f-8780-8027a480f21c`
**Live reference:** vividand.co

### Take
- Монументальный масштаб: display headlines 105–136px, line-height 1.00–1.01, вес 400 (не bold) — авторитет через размер, не жирность.
- Единственный источник цвета — "хроматическая призма" в hero (RGB-split через стеклянные кубы) на фоне монохромного интерфейса.
- Центрированная просторная компоновка, нет отдельных fill-кнопок, дифференциация только через spacing/scale.

### Don't take — ЯВНЫЙ ЗАПРЕТ ЮЗЕРА [REQ, повторено дважды]
**Подтверждённый факт (после открытия страницы):** палитра Vivid+Co буквально — near-black #101010 через blue-gray **#495764** к off-white #fffdf9. Именно этот диапазон (дымно-серо-голубой) юзер прямо запретил использовать. Взять ТОЛЬКО композиционный масштаб/типографику, палитру — игнорировать полностью, заменить на палитру Sequel/Aker (тёплый чёрный/кремовый/terracotta).

## 3. Cosmos

**URL:** `https://styles.refero.design/style/eb804e3a-1b75-446c-8374-114bbabaf0cd`

### Take
- Тёплый кремовый фон #f7f5f3 ("непрогрунтованный лён"), чёрные чернильные тексты, строго монохромный UI — цвет проникает только через пользовательские/реальные фотографии.
- Hero: свободная коллажная раскладка image tiles (scattered polaroids) вокруг центрированного текста; далее — трёхколоночная grid из image-led карточек.
- Единый signature radius (16px), повторяющийся на card/input/video — не смешивать разные радиусы.
- Нет градиентов, нет теней кроме естественных от коллажных карточек.

### Don't take
- Не превращать в соцсеть/бесконечную ленту — это галерейный, не UGC-контентный формат [REQ, план].

### Адаптация под Promonta
Применимо к `/projekte` (портфолио) — галерейная сетка + свободная коллажная подача до-факто вместо шаблонных карточек.

## 4. Aker — ОБЯЗАТЕЛЬНАЯ ОСНОВА ВЕРХА СЕРВИС-СТРАНИЦ [REQ]

**URL:** `https://styles.refero.design/style/4aa6d64c-fa61-4b21-8ad6-3d7130ed5161`
**Live reference:** akercompanies.com — посещён напрямую (текстовое описание не содержало структуру блоков 1-2, только палитру/типографику → по правилу пошли на live site)

### Block 1 (Hero, dark) — зафиксировано по скриншоту
- Full-bleed фото-фон (ландшафт/архитектура), затемнённый.
- Короткий tagline вверху слева (2-3 строки, светлый текст).
- Огромный wordmark внизу слева, крупные буквы поверх фото, обрезан краем экрана.
- Справа — плавающая тёмная карточка (полупрозрачная, rounded) с превью-фото + короткий текст-анонс + стрелка-CTA.
- Ниже — два pill-button ("Our team"/"Contact"-аналог) + два цветных квадратных блока-плитки (AI-платформа / Careers — аналог "быстрых ссылок").
- Минимальный chrome, никакого меню-бургера видно не было в первом экране.

### Block 2 (сразу после Hero) — зафиксировано по скриншоту
- Резкий переход: тёмный full-bleed фон → чистый белый холст.
- Один длинный serif/light-sans абзац слева (5 строк, крупный кегль, чёрный текст на белом), без изображения рядом.
- Огромный воздух вокруг текста (текст занимает ~30% высоты экрана).

### Take
- Именно эта пара (Block1: тёмный full-bleed фото-hero с wordmark+tagline+floating card CTA → Block2: резкий cut to белый холст с одним крупным текстовым заявлением) — обязательный паттерн верха КАЖДОЙ service-страницы [REQ].
- Типографика: вес 300 на display (62-168px) + вес 400-500 body — тот же приём "шёпот на большом кегле".
- Терракотовый акцент (единственный цветной элемент в системе) — можно рассмотреть как акцентный цвет Promonta вместо terracotta Aker (например, тёплый оранжевый/латунный).

### Don't take
- Не делать все 14 сервис-страниц идентичными — варьировать фото/акцентную плитку/CTA-текст.

## 5. ThoughtLab

**URL:** `https://styles.refero.design/style/82d52a5f-b1bb-4a69-91a3-15a7eb8bbe99`

### Take
- Чёрно-белая "cathedral" система: почти полностью ахроматична (#cccccc body, #ffffff display), единственный цветной элемент — один крупный CTA-pill (#fc1c46, аналог — можно заменить на брендовый акцент Promonta).
- Экстремальные скачки масштаба (198px → 14px) вместо цвета/теней для иерархии.
- Компоненты "невесомые": прозрачные карточки, hairline inputs, нет elevation/теней вообще.
- Принцип "дисциплина через вычитание": один шрифт, одна форма (pill), один акцент — при добавлении элемента первый вопрос "можно ли это убрать", а не "как стилизовать".

### Font — ПРОВЕРКА ЛИЦЕНЗИИ [REC-требование плана]
**Результат:** используемый шрифт называется "sui" — кастомный geometric sans без указания публичной лицензии/источника (не найден как публичный Google Fonts/Adobe Fonts). Трактуем как проприетарный шрифт ThoughtLab — **использовать нельзя** [REQ плана: не копировать чужие шрифты].
**Легальная замена (рекомендация):** Space Grotesk, Inter, или Neue Haas Groteske Display — любой достаточно геометричный gross grotesk с широким весовым диапазоном для воспроизведения контраста 198px/700 vs 14px/400.

### Don't take
- Сам шрифт "sui" — не использовать, см. выше.

## 6. Lusion

**URL:** `https://styles.refero.design/style/1b44386e-31a8-40b0-a577-27c088b51264`
**Live reference:** lusion.co — посещён (текст DESIGN.md не описывал конкретную scroll-механику → по правилу пошли на live site)

### Take
- Холодный lavender-tinted off-white холст (#f0f1fa) — вся хром-система "сидит" на нём, а весь цвет/драматизм даёт 3D-контент.
- Pill-компоненты с огромным радиусом (87-100px) — ощущаются как физические объекты на полу галереи, не как card stack.
- Тени сведены к 4% "шёпоту" — глубина создаётся 3D-рендером, а не UI-elevation.

### Depth/forward-motion механика — зафиксировано по факту посещения
На хиро — крупный 3D-объект (кластер синих/чёрных "крестовин", металлик-рендер) в затемнённой full-bleed рамке на общем lavender-фоне, с явным CTA "SCROLL TO EXPLORE". Сайт использует нестандартный/перехватывающий скролл (native `window.scrollTo` и синтетические wheel-события не двигали `scrollY` — типичный признак scroll-hijacking через WebGL-canvas с виртуальным прогрессом, а не через document-scroll). Технически это стандартный паттерн: **scroll position управляет Z-позицией камеры/объекта в Three.js-сцене**, создавая ощущение приближения объекта к зрителю. Дословно "объект летит на зрителя" — это камера, двигающаяся вперёд к статичному 3D-объекту (или наоборот, объект масштабируется/приближается по Z при скролле), а не покадровая анимация.

### Don't take
- Не пытаться воспроизвести полноценный WebGL/Three.js-рендер на каждой странице — точечно, 1 раз на сайте максимум [REQ план: "использовать точечно, не везде"].

## 7. Art+Commerce

**URL:** `https://styles.refero.design/style/bc4b420c-be08-4165-95a3-c8338b5a9c3c`
**Live reference:** artandcommerce.com — посещён (текст не описывал scroll/zoom-эффект)

### Take
- Editorial "art book spread on bone paper" — почти монохромный холст, крупноформатная фотография как весь визуальный язык.
- Типографическая пара: серифный Garamond-аналог (вес 400, единственный вес, display 56px) + функциональный grotesk в uppercase 8-10px с широким tracking (+0.027–0.038em) для навигации/метаданных — "музейные таблички".
- Нет бренд-цвета, градиента, тени, радиуса — иерархия только через чёрные чернила + white space + дисциплинированную сетку.

### Scroll/zoom эффект — зафиксировано по факту посещения
Полноэкранные фото-карточки, при входе в viewport — контент выстраивается в двухколоночную пару (изображение слева/треть ширины, заголовок+подзаголовок справа крупным Garamond). Явной покадровой записи процесса не поймали (статические скриншоты), но структурно это стандартный editorial-reveal: изображение слегка масштабируется (примерно 1.0→1.05) и/или фейдит при входе в вьюпорт, затем остаётся статичным — консервативный, тихий эффект, соответствующий общему сдержанному тону референса.

### Don't take
- Не копировать сами фото/ассеты (это модельное агентство, живые лицензированные фото).

## 8. Hyper Tria

**URL:** `https://styles.refero.design/style/6665a3dd-606f-4fd1-80dd-a84e3b3a6226`
**Live reference:** hypertria.com — посещён (текст не описывал искомую анимацию)

### Take
- Монохромная основа (чёрный/белый/один средний серый) + один яркий красный акцент (навигация, kicker-лейблы, wordmark) + один зелёный акцент только для вращающегося бейджа.
- Кастомный geometric sans на whisper-light весах (300) при почти-paragraph line-height (0.90-1.00), агрессивный негативный tracking на дисплейных размерах — буквы "запираются" в скульптурные композиции.
- Zero border-radius по всей системе — острые углы, "galery-meets-manifesto", не мягкий консьюмерский стиль.
- Hero: гигантские 3D chrome-буквы бренда (хромированный металлик-рендер) на чёрном фоне.

### Искомый эффект «картинка вверх / текст вниз» — РЕЗУЛЬТАТ ИССЛЕДОВАНИЯ
Прямого single-frame "картинка уходит вверх, текст одновременно уходит вниз, пара меняется на следующую" зафиксировать покадрово не удалось (сайт использует сглаженный/инерционный скролл, кадры получались между состояниями). Но по серии скриншотов чётко видна структура:
- Каждый проект — это пара: заголовок проекта (напр. "Porcelana", "Onoma Hotel") сверху слева + огромный статичный заголовок-слоган + full-bleed фото проекта справа/снизу.
- При скролле **текстовый блок уходит вверх и скрывается за sticky-header**, пока **изображение проекта остаётся на месте (нижняя часть экрана)** — эффект "плавающей sticky-картинки" с сквозным текстом.
- В момент когда текст полностью ушёл — на экране остаётся только изображение, потом **сразу появляется следующий проект**: новый заголовок нового проекта + новое изображение с новым акцентным цветным фоном (жёлтый → зелёный при смене Porcelana → Onoma Hotel) въезжают синхронно.
- Итоговый вывод: это **sticky-image + scroll-through-text паттерн**, где смена пары ощущается как единый синхронный "swap", потому что текст и картинка проекта визуально жёстко привязаны друг к другу и исчезают/появляются в одном скролл-сегменте. Это и есть тот эффект, который юзер описал как «картинка поменялась, текст поменялся — синхронно» — технически это не два независимых движения в разные стороны, а единый блок-transition между парами project-title+image.

### Don't take
- Красно-зелёный брендинг Hyper Tria (акцентные цвета) — не переносить, использовать собственную палитру Promonta [REQ].

## Сводные выводы для DESIGN_SYSTEM.md

1. **Основа палитры** — Sequel (near-black + тёплый ivory + 3 нейтральных серых), НЕ Vivid+Co blue-gray диапазон.
2. **Акцентный цвет** — терракотовый/тёплый (Aker-подобный) или другой тёплый акцент Promonta-бренда — не холодный серо-голубой.
3. **Типографика** — геометрический сан-сериф с широким весовым диапазоном (замена ThoughtLab "sui" — Space Grotesk/Inter/Neue Haas Grotesk Display), light weight (300) на display-размерах, обычный вес на body.
4. **Верх каждой service-страницы** — обязательный паттерн Aker Block1(тёмный full-bleed фото-hero + wordmark + floating CTA-card) → Block2(резкий cut в белый холст с одним крупным текстовым заявлением).
5. **Depth-эффект (точечно, 1 раз на сайте)** — Lusion-подобный scroll-driven приближение 3D-объекта к зрителю — не пытаться повторить полноценный WebGL, использовать упрощённо (например CSS 3D transform + scroll-linked scale/translateZ на одном герой-объекте).
6. **Editorial scroll-reveal (изображения)** — Art+Commerce-подобный лёгкий scale-in (1.0→1.05) + fade при входе в viewport.
7. **Project/portfolio pair-transition** — Hyper Tria-подобный sticky-image + scroll-through-text для `/projekte` карточек или секций "before/after".
8. **Portfolio-сетка** — Cosmos-подобная галерейная раскладка, кремовый фон, единый border-radius.

Всего задействовано моментов из референсов: Aker (top-of-page), Lusion (1 depth-момент), Art+Commerce (scroll-reveal), Hyper Tria (project-pair transition), Cosmos (portfolio grid), Sequel (общая палитра/типографика основа), ThoughtLab (шкала контраста веса+размера, с заменой шрифта), Vivid+Co (масштаб текста, БЕЗ палитры) — укладывается в заявленные юзером 10-15 motion-моментов на весь сайт [REQ, план блок 3], а не "по 10-15 на каждую страницу".
