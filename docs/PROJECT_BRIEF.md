# PROJECT_BRIEF.md — Grandmont Group Premium Website

Публичный краткий бриф проекта. Детальные рабочие решения фиксируются в профильных документах внутри `docs/`.

## Легенда тегов
- **[REQ]** — прямое требование владельца проекта. Менять нельзя без явного согласия.
- **[REC]** — рекомендация команды разработки. НЕ финальное решение владельца.
- **[DECIDE]** — открытый вопрос, требует явного ответа юзера.
- **[FINDING]** — наблюдаемый факт/баг, не требование.

## Контекст компании

Grandmont Group — строительная/монтажная компания в Chemnitz/Sachsen, Германия. Сайт строится с нуля как публичный многостраничный продукт для заявок, услуг, портфолио и будущей CRM-интеграции.

## Источники ТЗ

1. Владелец проекта — услуги, структура service-страниц, требования к форме заявки/калькулятору, Foto-Anfrage flow, интеграция с CRM, WhatsApp/телефон CTA, мультиязычность DE/EN, SEO, security/performance, анти-паттерны и customer journey.
2. Технический бриф — немецкая юридическая специфика (Anlage A HwO, §1 HwO wesentliche Tätigkeiten), DSGVO-специфика (§5 DDG, Art.13 DSGVO, §25 TDDDG), политика отзывов Google, CRM pipeline, SEO/URL-архитектура и AI-ready архитектура.

Цель: учитывать продуктовые, юридические и технические требования без потери важных деталей.

## Статус решений (см. полный список в мастер-плане)

РЕШЕНО (2026-09-24): стек Next.js/TypeScript; hosting/runtime details outside the public repository; группировка меню Montage/Ausbau & Renovierung/Objektservice; URL-структура без города в slug; возраст ЦА B2C 28-65 (ориентир); review-policy — нейтральная схема вместо gating.

ОТКРЫТО: CMS/content storage (MDX/JSON vs headless CMS) — решить перед Phase 1; Desktop CTA — отложено юзером до дизайн-макета (Phase 2); SERVICE_MATRIX — юридическое утверждение услуг, отдельный процесс, см. `SERVICE_MATRIX.md`.

## Полное содержание требований

Основные тематические блоки: позиционирование, motion-система, структура главной, услуги+юридический гейт, страница услуги, портфолио, доверие/преимущества, процесс работы, ЦА, конверсия/заявка, CTA, WhatsApp, телефон, CRM-архитектура, уведомления, AI future-ready, география, SEO-архитектура, B2B, Über uns, Kontakt, Ratgeber/блог, FAQ, отзывы, аналитика, юридическое/DSGVO, безопасность, performance, responsive/тестирование, accessibility, brand system, техническая архитектура, анти-паттерны и идеальный customer journey.
