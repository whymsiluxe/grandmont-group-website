# PROJECT_BRIEF.md — Grandmont Group Premium Website

Источник истины: `~/.claude/plans/elegant-booping-wren.md` (master plan, полностью утверждён юзером после 3 раундов правок тегов). Этот файл — копия-выжимка для репозитория, структура и теги [REQ]/[REC]/[DECIDE]/[FINDING] идентичны мастер-плану. При любом расхождении — мастер-план в приоритете.

## Легенда тегов
- **[REQ]** — прямое требование юзера. Менять нельзя без явного согласия.
- **[REC]** — рекомендация Claude/ChatGPT. НЕ решение юзера.
- **[DECIDE]** — открытый вопрос, требует явного ответа юзера.
- **[FINDING]** — наблюдаемый факт/баг, не требование.

## Контекст компании

Grandmont Group — строительная/монтажная компания в Chemnitz/Sachsen, Германия (новый отдельный бизнес, не связан с существующей компанией Promonta юзера). Владелец — с украинскими корнями [REQ, чувствительный момент, см. блок 8.2 ниже]. Сайт строится с нуля.
